jan11_App_dev プライバシーポリシー

jan11_App_dev は、開発者 jan11 が自分のアプリの数字を確認するためだけに使う、非公開の社内ツールです。一般の利用者向けには公開していません。

取得する情報

開発者本人の Google アカウントで許可を得て、AdMob API から自分のアプリの広告レポート(表示回数・リクエスト数・推定収益など)を読み取ります。権限は読み取り専用(admob.readonly)で、AdMob の設定を変更することはありません。

使いみちと保存

読み取ったレポートは、開発者本人だけが見られるダッシュボードの表示にのみ使います。データは非公開のリポジトリと、パスワードで保護したページに保存します。第三者への提供・販売・広告目的での利用はしません。

Google ユーザーデータの扱い

Google API から受け取った情報の利用と他アプリへの転送は、Google API Services User Data Policy(Limited Use の要件を含む)に従います。

許可の取り消し

Google アカウントの サードパーティ製のアプリとサービス から、いつでも許可を取り消せます。
